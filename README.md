\# 🌍 TripMe - Agência de Viagens



Projeto desenvolvido como parte da \*\*Certificação 1\*\* do curso de \*\*DEVstart\*\*. A página é uma Landing Page para uma agência de viagens focada em vilarejos europeus e destinos remotos.



\## 🚀 Tecnologias Utilizadas

\* \*\*HTML5\*\*: Estrutura semântica e acessibilidade.

\* \*\*CSS3\*\*: Layout responsivo, efeitos de hover e estilização moderna.

\* \*\*JavaScript\*\*: Interatividade com o usuário e manipulação básica do DOM.



\## 📋 Requisitos Atendidos

\- \[x] Banner principal com overlay de texto.

\- \[x] Navegação interna via IDs.

\- \[x] Seções: TripMe, MeetUs e Advice (MinhaViagem, NosEncontre, Conselhos).

\- \[x] Botões e links com efeitos visual ao passar o mouse (:hover).

\- \[x] Acessibilidade com textos alternativos nas imagens.

\- \[x] Funcionalidade de captura de contato via prompt.



\## 🛠️ Como executar o projeto

1\. Clone o repositório.

2\. Abra o arquivo `index.html` em qualquer navegador.
